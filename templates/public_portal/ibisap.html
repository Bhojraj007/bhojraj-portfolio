On-Premises / Dedicated Cloud

Enterprise IbiSAP

Engineered for Institutions Requiring Strict Data Sovereignty

Designed for regulated microfinance institutions (MFIs), cooperatives, hospitals, and large enterprises requiring NRB IT compliance, dedicated PostgreSQL/SQL HANA database servers, and maker-checker workflows.

  • On-Premises & Private Cloud Deployment Complete data sovereignty on your physical hardware or dedicated private virtual cluster.
  • NRB IT Security Guidelines Compliant Granular RBAC, dual-authorization (maker-checker), automated DRP backups, and immutable audit logs.
  • Native Nepali Miti (Bikram Sambat) Engine Dual-calendar fiscal accounting (Shrawan 1 to Ashadh 31) with bi-directional AD/BS conversion.
  • Certified IRD CBMS Real-Time Invoicing Direct REST API synchronization with the Inland Revenue Department with offline failover queues.
  • Dedicated PostgreSQL / SQL HANA Instance Pessimistic row-level locking (`select_for_update`) guaranteeing ledger transaction consistency.
